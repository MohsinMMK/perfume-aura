# B03 — 49-name catalog reconciliation

Audit date: 2026-08-29. Decision owner: COM-ADR-033.

This packet records the requested research and classification of the 49 replacement-source names that did not previously have a storefront title. It is identity research and catalog organization, not trademark clearance. Inspired names remain subject to India-counsel review for every intended public surface. Unknown is a temporary collection label and preserves the supplied fragrance name and all supplied prices without inventing a brand.

## Result

- 34 rows mapped to Inspired using official or strongest-available identity evidence.
- 15 rows placed in temporary Unknown because the source is generic, brand-only, multi-brand, conflicting, or not exact enough to map safely.
- Final catalog: 79 Inspired + 15 Unknown + 20 Signature = 114 products.
- Prices are unchanged: main rows 1–16 retain ₹600/₹800/₹1,400; main rows 17–94 retain ₹450/₹650/₹1,200; Signature retains its supplied 50/105 ml prices.

## Naming options for the temporary section

- **Aura Originals** — strongest future house-name option if these are confirmed as Perfume Aura-created identities.
- **Independent Scents** — neutral and useful while brand/reference provenance remains mixed.
- **Fragrance Collection** — the safest descriptive option when no origin claim should be made.

The storefront intentionally uses **Unknown** until the owner selects a permanent label.
